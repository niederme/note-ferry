Note Ferry 1.2.1 improves formatting for text pasted into Apple Notes.

- **Preserve table grids.** Markdown tables keep their rows, columns, headers, and wrapped cell text in the preview and rich clipboard output, including tables copied from ChatGPT Meetings.
- **Keep bullet wrapping aligned.** Copying selected text from the formatted preview now preserves native list formatting, so wrapped lines align with the item text after pasting into Notes.
- **Format meeting action prompts.** ChatGPT Meetings' `codex-prompt` blocks become readable action-item bullets, including when the source is wrapped in an extra code fence.
- **Handle more Markdown patterns.** Improved support for nested lists, checklist symbols, quotes, divider lines, alternate heading syntax, image descriptions, and line breaks. Checklist symbols remain text; select the items and use Notes' Checklist button to make them clickable.
- **Use a consistent Codex model.** Codex summaries explicitly use GPT-5.6 Sol with medium reasoning effort rather than the installed CLI's default. Your Codex account and CLI must support that model; Note Ferry does not silently switch models if it is unavailable. Unavailable models now show a specific message instead of a generic connection failure.

### Install or update

Choose **Note Ferry → Check for Updates…**, or download **Note-Ferry-1.2.1-universal.zip**, unzip it, and move **Note Ferry.app** to Applications, replacing the previous copy.

Version 1.2.1 is build 6. The universal app supports Apple silicon and Intel Macs and requires macOS 14 or later. Apple Intelligence needs macOS 26 or later and compatible hardware. Runtime testing has been on Apple silicon with macOS 27; Intel hardware and older macOS versions have not been tested. **Format only** continues to run locally without AI.
