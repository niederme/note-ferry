Note Ferry 1.2.5 improves Codex setup for different installations and account types.

- Note Ferry no longer forces a Sol model. Codex chooses its default, or you can enter a model ID available to your account in **Settings → Codex model**.
- Codex installed through npm or nvm can now be found even when Terminal has a different PATH from the app.
- npm installations keep their Node.js runtime available when Note Ferry starts Codex, including installations in folders with spaces and symlinked launchers.
- A missing Node.js runtime now shows a specific setup message instead of reporting that Codex is missing.

Version 1.2.5 is build 10. The universal app supports Apple silicon and Intel Macs and requires macOS 14 or later. **Format only** still runs locally without AI.
