Note Ferry 1.2.3 makes Claude API key setup easier to finish.

- Paste a key directly into Settings, or choose **Paste from clipboard** to save and check it in one step.
- Keys that work across workspaces can use a selected workspace. If Note Ferry needs a workspace ID, the key stays saved while you add it.
- Key entry uses a regular text field, and saving leaves the clipboard unchanged.
- Connection and setup messages are shorter and more specific.

Version 1.2.3 is build 8. **Format only** still runs locally without AI.
